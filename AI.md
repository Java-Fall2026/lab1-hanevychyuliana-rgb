# Звіт про використання штучного інтелекту

**1. Ключовий промпт:**
> "Напиши чіткі команди для терміналу Mac, щоб переключитися з першої лабораторної роботи на нову гілку lab2 та правильно відправити зміни на GitHub."

**2. Що AI зробив неправильно:**
AI надав точний і коректний набір Git-команд (`git checkout -b lab2`, `git add .`, `git commit`, `git push`), тому жодних помилок чи хибних порад з його боку не було.

**3. Що було зроблено самостійно:**
Після підказки з командами для Git усю практичну частину лабораторної роботи №2 я виконала повністю самостійно:
- створила необхідні `enum`-и (`RoomType` з власним коефіцієнтом та `BookingStatus`);
- рефакторила класи `Guest` та `HotelPayment` у `record`, винесла валідацію в компактні конструктори;
- вилучила успадкування `BaseEntity` з `record`-ів і додала `createdAt` у параметри;
- написала два `switch`-вирази зі стрілками `->` у `HotelUtils`;
- наповнила клас `Main` для демонстрації всіх потрібних сценаріїв.
