### 🤖 Використання AI

Під час виконання п'ятої лабораторної роботи я самостійно спроєктувала ієрархію доменних репозиторіїв з успадкуванням від GenericRepository<T>, реалізувала інтерфейс Comparable<T> через безпечні компаратори та розробила комплексні методи пошуку й агрегації за допомогою Stream API.Для консультації я зверталася до ChatGPT із таким промптом: "Як у Java за допомогою Stream API реалізувати багаторівневий компаратор із використанням thenComparing та nullsLast для доменного класу з урахуванням специфікації Comparable?".У запропонованому варіанті коду асистент спочатку запропонував використати застарілі цикли for та пряме віднімання полів для сортування, що суперечить умовам завдання (оскільки віднімання дробових чисел може давати нуль там, де є різниця). Я самостійно відкинула цей підхід і переписала сортування через чисті виклики Stream API з використанням Comparator.comparingDouble() та Integer.compare().Також самостійно реалізувала перевірку одноразовості стріму через перехоплення IllegalStateException та написала модульні тести для не узгодженого з equals компаратора у TreeSet.
