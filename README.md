### 🌳 Поведінка TreeSet із компаратором, не узгодженим з equals

Якщо `TreeSet` ініціалізується з власним `Comparator` (наприклад, таким, що порівнює кімнати виключно за ціною `Comparator.comparingDouble(Room::getPricePerNight)`), то структура даних визначає еквівалентність елементів саме через цей компаратор (якщо `compare()` повертає `0`), а не через метод `equals()`.  Якщо до такого `TreeSet` додати дві різні кімнати з абсолютно однаковою ціною (але різними номерами), `TreeSet` сприйме другу кімнату як дублікат першої та відхилить її. У результаті в колекції залишиться лише **1 елемент**, хоча метод `equals()` цих двох об'єктів повертає `false`.
